# Contributing

[한국어](CONTRIBUTING.md)

Thank you for your interest in Deplite validate-action.

This repository is a client for the Deplite service. We do not merge pull requests from outside the team. Please open an issue to report a bug or request a feature.

## Reporting a bug

- Steps to reproduce
- Runner environment and action version
- Expected and actual behavior
- Error messages

Please redact tokens and install codes.

## Requesting a feature

Tell us what you were trying to do and how you work around it today.

## Security vulnerabilities

Please do not report security vulnerabilities through public issues. Use the [private report form](https://github.com/Deplite/validate-action/security/advisories/new) under the repository's Security tab.
